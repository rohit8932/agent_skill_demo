# This is skill demo 

## What we achive by this project? 
- By making skill, you are giving your private/custom skill to agent/LLM.
- By having this you are not relying upon LLM trained expertise. 
- By having this you can set the gurdrails, boundaries.

## What we have into the project? 
- We have three styles of salad, 
- 1. Indian, 2. Mexican, 3. Mediterranean
- Initially we have SKILL.md just to give idea and then reference folder which contains detailed steps. (Progressive desclosure)
- We also have python script which agent calls when recipe is ready to celeberate. to showcase skill can call deterministic code as well.
- we also have assets, these are reusable assets which we can use while generating output.

## How to call skill
- ask in chat window like, give me recipie for indian/mexican/mediterranean style salad.
- Note: if you give typo like mixicaaan or MEXICAN. the LLM will correct and use the skill accordingly. 
- you will notice this when LLM calls deterministic function, this method takes smallcase salad name.
